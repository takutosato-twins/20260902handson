# データについて

- **データセット名**: Energy Efficiency
- **提供元**: UCI Machine Learning Repository
- **作成者**: Tsanas, A. and Xifara, A.
- **ライセンス**: Creative Commons Attribution 4.0 International (CC BY 4.0)
  （データセットに対するライセンスです。本リポジトリのコードのライセンスとは別です）
- **元データURL**: https://archive.ics.uci.edu/static/public/242/data.csv
- **データセットページ**: https://archive.ics.uci.edu/dataset/242/energy+efficiency

## ファイル

- `energy_efficiency.csv`: 上記URLから取得した生データをそのまま同梱したものです

## 内容

- 768行（ヘッダ行を除く）
- 入力特徴量: X1〜X8（建物の設計情報）
- 出力変数: Y1(Heating Load), Y2(Cooling Load)

## このアプリでの使用方法

- **目的変数として使用するのは Y1 (Heating Load) のみです**
- **Y2 (Cooling Load) は今回のアプリでは使用しません**

## 取得時の検証情報

- 取得時のSHA-256: `db44dbe453acd464b5cf65be2fb01a28aa9c5b2630300e65fbe28cde35f5d96f`
- 取得時にHTTPステータス200、CSV形式（HTMLエラーページ等でないこと）を確認済みです

## 参加者への注意

このデータはリポジトリに同梱済みのため、**参加者が別途ダウンロードする必要はありません**。
