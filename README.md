# 勾配降下法ハンズオン

学習率とミニバッチサイズを変えながら、ミニバッチ勾配降下法の学習速度・安定性・収束の違いを
体験するためのハンズオン用Webアプリです。PythonやGit、ライブラリ、データを自分の環境に
インストールしなくても、ブラウザでURLを開くだけで操作できます。

## アプリの目的

- 学習率・ミニバッチサイズを変えたときに、勾配降下法の学習がどのように変化するか
  （速く収束する／なかなか収束しない／不安定になる／発散する、など）を実際に動かして体験する
- 損失曲線と予測結果の散布図を見比べながら、ハイパーパラメータの効果を理解する

## タスクについて

建物の設計情報（相対的コンパクト性・表面積・壁面積・屋根面積・全体高さ・方角・
グレージング面積・グレージング面積分布の8つの特徴量）から、**暖房負荷(Heating Load)**を
線形回帰で予測する回帰タスクです。モデルはNumPyで自前実装したミニバッチ勾配降下法で
学習します（scikit-learnの学習機能は使用していません）。

## 参加者が変更できるパラメータ

| パラメータ | 選択肢 | 初期値 | 説明 |
|---|---|---|---|
| 学習率 | 0.0001, 0.001, 0.003, 0.01, 0.03, 0.1, 0.3, 1.0 | 0.01 | 1回のパラメータ更新でどれだけ重みを動かすか。大きいほど学習は速く進みうるが、不安定・発散しやすくなる |
| ミニバッチサイズ | 1, 2, 4, 8, 16, 32, 64, 128, 256, 全件 | 32 | 1回の勾配計算に使うデータ数。小さいほど更新回数は増えて学習の様子はノイジーになり、大きいほど1回あたりの計算は安定するが更新回数は減る |
| 最大エポック数 | 50, 100, 300, 500 | 300 | 学習データ全体を何周するか。上限に達するか、発散・タイムアウト・中断が起きると学習は終了する |

学習開始時に選択した値は「今回の実行条件」として学習中固定され、学習が終わるまで
パラメータ選択は変更できません。

## 画面の見方

- **進捗状況・エポック数・更新回数・経過時間・終了理由**: 学習の進み具合をリアルタイムに表示します
- **学習データの損失 (Train MSE) / テストデータのMSE・RMSE**: いずれも元のHeating Load単位に
  戻した値です。Test MSEは小さいほどよく、Test RMSEは「予測が実際の値からどの程度ずれているかの
  目安」（Heating Loadと同じ単位）です
- **損失曲線 (Training Loss)**: 横軸がエポック、縦軸が学習データに対する誤差(Train MSE)です。
  右肩下がりに滑らかに下がっていれば順調に学習が進んでいます。途中で跳ね上がっている場合は
  学習率が大きすぎる可能性があります
- **実測値と予測値の散布図 (Actual vs Predicted)**: テストデータについて、横軸が実際の
  Heating Load、縦軸がモデルの予測値です。点が赤い対角線(y=x)に近いほど予測が正確です
- **終了理由**: 正常終了・早期終了・手動中断・制限時間超過・発散検知・エラーのいずれかが表示されます

グラフはエポックが変わるたびではなく、数エポックごと（チャンク単位）にまとめて更新されます。

## 今回のランキングルール

参加者同士で結果を比較する際は、以下の条件をそろえてください。

- 最大エポック数: **300**
- 乱数シード: **42**（アプリ内部で固定済み、変更不可）
- 変更してよいのは **学習率とミニバッチサイズのみ**
- **Test MSEが小さいほど上位**

## ローカルでの起動方法

```bash
# 依存パッケージのインストール
pip install -r requirements.txt

# アプリの起動
streamlit run app.py
```

ブラウザで `http://localhost:8501` が自動的に開きます。データはリポジトリに同梱済みのため、
別途ダウンロードする必要はありません。

## Streamlit Community Cloudへのデプロイ方法

1. このリポジトリをGitHubにpushする
2. [Streamlit Community Cloud](https://streamlit.io/cloud) にログインし、「New app」を選択する
3. デプロイ元リポジトリ・ブランチを選択し、Main file pathに `app.py` を指定する
4. 「Deploy」をクリックすると、`requirements.txt` に基づいて依存パッケージが自動インストールされ、
   アプリが公開される
